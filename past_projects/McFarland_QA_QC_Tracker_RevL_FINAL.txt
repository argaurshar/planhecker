REVIEW PROTOCOL — SEVERITY, CATEGORIES, STATUS CONVENTIONS

APPROACH	Sheet-by-sheet review. One tab per architectural sheet. Each finding numbered within that sheet (e.g. AG01-F001). Rev 0 / Rev A / Rev B / Rev C columns track response across submissions.
FINDING ID	Format: [SheetCode]-F### (e.g. AG01-F001, AG02-F001). Keep unique per sheet.
CODE COLUMNS	Each finding checked against 2022 code (primary) AND 2025 code (parallel). Differences flagged explicitly.

SEVERITY	DEFINITION
Critical	Will cause plan check rejection or life-safety concern. Must be resolved before submission.
Major	Likely correction letter item. Resolvable but will delay permit issuance.
Minor	Plan check may or may not flag. Good practice to fix.
Observation	Not a defect — noted for client or internal quality reasons.

STATUS	MEANING
Open	Raised, not yet addressed by team.
In Progress	Assigned, work underway.
Resolved	Fix made and verified against latest sheet rev.
Deferred	Parked intentionally — consultant or AHJ response pending.
Not Applicable	Reviewed and determined not to apply.

CATEGORY	SCOPE
Jurisdictional	Wrong AHJ referenced (e.g. Mountain View text on Saratoga project).
Zoning	Saratoga Muni Code Art 15 — setbacks, FAR, coverage, height.
Calculation	Area tabulations, math errors, cross-table consistency.
Code-CBC	California Building Code.
Code-CRC	California Residential Code — egress, smoke/CO, R313 sprinklers.
Code-T24	Title 24 Part 6 energy.
Code-CALGreen	Title 24 Part 11.
Code-CFC	California Fire Code + Saratoga local amendment.
Code-CEC	Electrical.
Code-CMC	Mechanical.
Code-CPC	Plumbing.
Drafting	Line work, template artifacts, legends, schedules.
Notes	General notes, sheet notes, code citations.
Drawing List	Sheet index errors.
Cross-Sheet Coord	Same item shown differently on multiple sheets.
Professional	License numbers, seals, responsible party.
Vaastu	Firm standard — orientation and zonal compliance.
Miscellaneous	Anything else.
