# San Jose — city-specific rules

## Zoning (San Jose Municipal Code Title 20)
- Single-family zones: R-1, R-2 — verify the specific zone's setback, FAR, height, and lot coverage limits
- ADU rules: San Jose allows ADUs per state law minimums; some local enhancements apply
- Hillside development: stricter rules apply on slopes ≥ 10% — slope-adjusted FAR, geotechnical review

## Building (San Jose Municipal Code Title 17)
- Local CBC/CRC amendments — verify edition currently adopted (typically follows state cycle within 6–12 months)
- Permit fees and plan-check turnaround per published San Jose Building schedule

## Reach codes
- San Jose has a long-standing electrification reach code requiring all-electric for most new residential construction
- Verify current status — reach codes are challenged in court periodically; the requirement may change
- If the project includes gas service, document the AHJ-approved exception

## Common San Jose plan-check items to flag
- Cover sheet must state San Jose code cycle (typically 2022 CBC/CRC or 2025 — verify vesting)
- Site plan must show all setbacks against zone-specific minimums
- Tree-protection plan often required if removing protected trees (Heritage Tree Ordinance)
- Construction & Demolition (C&D) recycling plan required — flag if missing
- Stormwater compliance per San Jose's MRP (Municipal Regional Permit) — C.3 provisions for projects creating/replacing 2,500+ sq ft of impervious surface
