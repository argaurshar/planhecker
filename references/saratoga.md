# Saratoga — city-specific rules

## Zoning (Saratoga Municipal Code, Article 15)
- Common single-family zones: R-1-15,000, R-1-20,000, R-1-40,000 (number = minimum lot size in sq ft)
- Setbacks vary by zone — verify against the specific zone's table
- Height limit: typically 26 ft maximum for residential (verify current code; Saratoga is strict)
- FAR: slope-adjusted on hillside lots — actual allowed FAR drops as average slope increases
- Lot coverage: capped per zone; impervious-coverage limits also apply on some lots

## Hillside development
- Slope-adjusted FAR formula reduces allowable floor area as average slope increases
- Geotechnical investigation required for sloped lots
- Cut/fill restrictions and import/export limits often apply

## Wildland-Urban Interface (WUI)
- Most of Saratoga is inside a Very High or High Fire Hazard Severity Zone
- CBC Chapter 7A / CRC R337 applies — ignition-resistant materials, Class A roof, ember-resistant vents, defensible space
- Saratoga's WUI overlay may extend beyond state maps — verify lot status with Saratoga Planning AND SCCFD (Santa Clara County Fire)

## Heritage Trees
- Saratoga has a Heritage Tree Ordinance — many native species are protected at quite small trunk diameters
- Tree survey + arborist report typically required at design review
- Removal/encroachment requires permit; replacement plantings often required

## Site Development Permit / Design Review
- Saratoga uses a Design Review process for many SFR additions, ADUs, and new construction
- Setbacks at maximum, height at maximum, view-protection considerations all factor
- Adjacent-property notification often required; design review can add 4–8 weeks to schedule

## Common Saratoga plan-check items to flag
- Cover sheet must state code cycle and verified vesting (Saratoga is meticulous about this)
- Slope-adjusted FAR calculation must be shown and verified against survey-derived average slope
- Height calculation methodology — Saratoga measures from a specific natural-grade methodology; flag if drawing uses different baseline
- WUI compliance — call out CRC R337 / CBC Chapter 7A measures explicitly on sheets
- Defensible space / fuel reduction plan within 100 ft of structures (CRC R337.1.4 / Public Resources Code §4291)

## AHJs commonly involved
- Saratoga Planning Division (zoning, design review, FAR, setbacks, height)
- Saratoga Building Division (CBC/CRC, structural, mechanical)
- Santa Clara County Fire Department (SCCFD) — WUI, hydrants, access
- Santa Clara County Public Works (PW) — civil, drainage, street improvements
- Cupertino Sanitary District / West Valley Sanitation — sewer (verify per project)

(Saratoga's interpretation of zoning rules can be stricter than the
written code suggests. When a finding touches setback, height, or FAR,
flag for AHJ verification with Saratoga Planning specifically.)
