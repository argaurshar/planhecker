# General checks (apply to every drawing, regardless of project)

## Title block
- Every drawing must have a title block with: project name, address, sheet number, sheet title, scale, and drawing date
- The title block must clearly identify the architect / firm and the licensed professional of record
- A revision marker (e.g., "Rev. A", "Rev. 0") must be present
- Code cycle (e.g., "2022 CBC / CRC" or "2025 CBC / CRC") must be stated on the cover sheet — flag any drawing with no code cycle stated

## Drawing fundamentals
- Every plan view must have a north arrow
- Every drawing must have a clearly labeled scale (graphic bar AND numeric ratio preferred)
- Dimensions should be in feet and inches (US imperial) — flag any metric-only or mixed-unit drawings as a coordination concern
- Every door must show its swing direction
- Every window must be schedule-keyed (e.g., W-01, W-02) and dimensioned

## Annotation completeness
- Every room must be labeled with its name (Bedroom, Kitchen, Bath, etc.) AND its area in square feet
- Every wall thickness should be specified
- Floor levels and finish elevations should be called out
- Lot lines, setback lines, and easements should be clearly distinguished

## Project-set hygiene (catches inter-sheet inconsistencies)
- Sheet index on the cover should match the actual sheets in the set
- Drawings should reference each other consistently (e.g., section cuts on plan should land on the correct section sheet)
- If a drawing references a detail (e.g., "see 3/A5.1") the referenced detail must exist
